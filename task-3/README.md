# 🎵 Task 3 - AI Music Generator

## 📌 Project Overview

This project is an AI-powered Music Generator developed as part of the CodeAlpha Artificial Intelligence Internship.

The application uses the **MusicGen AI model** to generate original music based on a text description provided by the user.

## ✨ Features

- 🎵 AI-powered music generation
- 📝 Text-to-music prompt
- 🎚️ Select music duration
- 💾 Save generated music as WAV
- 🖥️ User-friendly graphical interface
- ⚠️ Error handling and status messages
- ✨ Example prompts for easy testing

## 🤖 AI Model

**MusicGen Small**  
Model: `facebook/musicgen-small`

The model generates music based on natural-language descriptions.

## 🛠️ Technologies Used

- Python
- Tkinter
- PyTorch
- Hugging Face Transformers
- MusicGen
- NumPy
- SoundFile
