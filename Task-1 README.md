# Task 1 - Language Translation Tool

## 📌 Project Overview

This project is a simple Language Translation Tool developed as part of the CodeAlpha Artificial Intelligence Internship.

The application allows users to enter text, select a source language and target language, and translate the text using a translation API.

## ✨ Features

- Select source language
- Select target language
- Enter text for translation
- Translate text using an online translation API
- Display translated text clearly
- Copy translated text to clipboard
- Clear input and output
- Error handling for connection and translation issues

## 🛠️ Technologies Used

- Python
- Tkinter
- Requests
- MyMemory Translation API

## 🌐 Supported Languages

The application supports:

- English
- Hindi
- Punjabi
- French
- Spanish
- German
- Italian
- Portuguese
- Russian
- Japanese
